# Changelog

All notable changes to Hermes Town are documented here.

## 0.1.0 - 2026-09-14

Initial developer preview.

- Added the Phaser pixel-art town and scripted demo mode.
- Added the passive native Hermes lifecycle bridge.
- Added the authenticated loopback ingest server, read-only snapshot, SSE stream, and bounded journal.
- Added privacy-contract, server-contract, build, browser, and plugin-loader verification.
- Added explicit local-only deployment guidance and MIT licensing.
